## Wordle Clone

A minimal, browser-based word‑guessing game inspired by Wordle. Guess the 5‑letter answer in up to 6 tries using intuitive color feedback. Built with pure HTML, CSS, and JavaScript. ([github.com][1])

### &#x20;Try it

Visit the live version: [unknownexplosion.github.io/wordle/homepg.html](https://unknownexplosion.github.io/wordle/homepg.html) ([github.com][2])

### Features

* Daily-style 5-letter word guessing with colored clues (green = correct spot, yellow = wrong spot, gray = not in word)
* Responsive, lightweight implementation — no frameworks required

### Quick Start

```bash
git clone https://github.com/unknownexplosion/wordle.git
open homepg.html
```

Play instantly—no setup needed!
